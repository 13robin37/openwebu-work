# Changelog

All notable changes to Rich Email Composer are documented here.

## 1.0.0 - 2026-09-11

Initial public release.

- added interactive Rich UI email drafting inside Open WebUI chats;
- added direct editing for recipients, subject, and body;
- added AI-assisted revision requests using the current edited draft;
- added contextual body formatting with headings, lists, checklists, inline formatting, code, and emoji;
- added recipient validation, duplicate protection, field limits, and optional domain allow/block policies;
- added light/dark themes and responsive mobile behavior;
- added rich/plain clipboard copy, mail-client handoff, and multipart `.eml` export;
- added long-mailto fallback behavior;
- added message-level embed rendering with inline HTMLResponse fallback;
- added sanitization, Base64 payload transport, header cleaning, and no-external-assets policy;
- removed deployment-specific branding, domains, and institutional styling from the public version.
